1. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create web pages.

Uses of HTML

  • Creating websites.
  • Adding headings and paragraphs.
  • Inserting images and videos.
  • Creating links and tables.
  • Building forms.

2. Basic Structure of HTML

Every HTML document follows a basic structure.

<!DOCTYPE html>
<html>
<head>
  <title>My Website</title>
</head>
<body>
  <h1>Hello World</h1>
  <p>Welcome to HTML.</p>
</body>
</html>

Explanation

  • <!DOCTYPE html> – Declares HTML5.
  • <html> – Root element of HTML.
  • <head> – Contains page information.
  • <title> – Sets the browser tab title.
  • <body> – Contains visible page content.

4. HTML Attributes

Attributes provide additional information about HTML elements.

Attribute Meaning
href Specifies a link destination.
src Specifies an image or media source.
alt Alternative text for an image.
width Sets width.
height Sets height.
id Unique identifier.
class Groups elements for styling.

Example

<a href="https://www.google.com">
  Visit Google
</a>

5. What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and design HTML documents.

Uses of CSS

  • Changing text color.
  • Setting background colors.
  • Adjusting font size.
  • Creating layouts.
  • Making websites responsive.
  • Adding borders and shadows.

6. CSS Selectors

Selector Example Meaning
Element p { } Selects all paragraphs.
Class .box { } Selects elements with class box.
ID #title { } Selects an element with ID title.
Universal * { } Selects all elements.
Hover a:hover { } Applies style on mouse hover.

7. Important CSS Properties

Property Function
color Changes text color.
background-color Changes background color.
font-size Changes text size.
font-family Changes font style.
text-align Aligns text.
margin Creates space outside an element.
padding Creates space inside an element.
border Adds a border.
display Controls element layout.
width Sets element width.
height Sets element height.

8. Types of CSS

1. Inline CSS

CSS written inside an HTML element.

<p style="color:red;">
  Hello World
</p>

2. Internal CSS

CSS written inside the style tag in the head section.

<style>
p {
  color: blue;
}
</style>

3. External CSS

CSS written in a separate .css file.

<link rel="stylesheet" href="style.css">
